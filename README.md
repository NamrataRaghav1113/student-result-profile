# Student Result System (Python)

This is a simple Python-based **Student Result System** program.
It takes student details, subject names, and marks as input,
then calculates **total marks, percentage, and grade**.

---

## 🚀 Features
- Takes student personal details
- Accepts 6 subject names and marks
- Calculates total marks
- Calculates percentage
- Displays grade based on percentage
---

## 🧮 Grade Criteria
- **First Division** → 65% and above  
- **Second Division** → 55% to 64%  
- **Third Division** → 33% to 54%  
- **Fail** → Below 33%
